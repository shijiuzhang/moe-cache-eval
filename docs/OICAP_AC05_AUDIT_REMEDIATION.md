# OICAP AC05 audit remediation

**Audit source:** `OICAP_AC05_AUDIT.md`  
**Status:** implementation complete; awaiting independent confirmation

The audit accepted V02-AC05 and left G1–G3 open. This note maps each finding to
the implementation and adversarial evidence without modifying the auditor's record.

## G1 — legacy ruleset provenance and adjudication

- `verify` now reports the declared, applied and current metrics rulesets.
- Missing declarations are explicitly recorded as an assumed legacy ruleset.
- Any non-current ruleset emits `superseded_metrics_ruleset:<version>` and reports
  `current_metrics_semantics: false` and `adjudication_eligible: false`.
- v0.2 specification §18 now separates successful compatibility recomputation from
  adjudication eligibility. Legacy TPOT and ITL must produce
  `INSUFFICIENT_EVIDENCE / SUPERSEDED_METRIC_SEMANTICS` if offered to a v0.2 gate.
- A genuine bundle generated by the frozen v0.1 code is committed under
  `tests/fixtures/oicap/v0_1_genuine_bundle/`. The current verifier reproduces it
  exactly while emitting the superseded-ruleset warning.

## G2 — synthetic timing provenance and endpoint identity

- The deterministic server now emits
  `X-OICAP-Test-Protocol: deterministic-sse-v1`.
- The adapter requires that response-side identity before accepting synthetic
  per-content-event timing. Merely placing `oicap_test` in a request to an endpoint
  that ignores unknown fields no longer passes.
- Current summaries carry `token_timing.declared_authorities`; synthetic samples use
  `synthetic_available`, never bare `available`, and explicitly state that they are
  ineligible for production per-token latency adjudication.
- AC05 protocol case records now include `token_timing_authority`.
- Positive controls cover an unmarked endpoint that otherwise implements the same
  response shape and a correctly marked deterministic endpoint.

Historical shapes are preserved: `0.1` and `0.2-dev1` summaries continue to
recompute byte-for-byte. The new provenance shape is `metrics_version: 0.2-dev2`.

## G3 — private procurement material

`.gitignore` now excludes `private/` as a whole. The blank rehearsal templates stay
public, but every populated source record, tender extract, working note and sibling
directory under that root remains invisible to Git.
